よくある質問

見つかりませんでした。別のことばで探すか、下の「お問い合わせ方法」からご連絡ください。

導入・インポート

Qunitypackage をインポートできない（Couldn't decompress package と出る）

ファイル名を日本語に変えると、Unity が読み込めなくなります。ダウンロードしたときの名前（Pet_Kipfel_Ver〜／Pet_Mamehinata_Ver〜）のままインポートしてください。

Q導入画面が開かない

Unity の上のメニューの Tools›連れ歩きギミック›導入する から開けます。

メニュー自体が出てこないときは、Console に赤いエラーが出ていないか確認してください。VRChat SDK - Avatars 3.7 以上と Modular Avatar 1.10 以上が、VCC で入っている必要があります。

Q「連れていく」にキプフェル・まめひなたが出てこない

このギミックには、キプフェル・まめひなた本体は入っていません。同じプロジェクトに、キプフェル Ver1.2.0 以降／まめひなた Ver1.60 以降をインポートしてください。

Q自分のアバターとして使っている（アップロード済みの）キプフェルを連れていきたい

別のプロジェクトで使っている・VRChat にアップロード済みのキプフェル／まめひなたを、そのままインポートして連れていくことには対応していません。

同じ衣装を着せたいときは、導入画面の「追加衣装」に、同じ衣装の Prefab を入れてください。

Qキプフェル版とまめひなた版を両方使いたい

両方インポートすると、「連れていく」でどちらも選べます。両方入れるときは、同じバージョンどうしにしてください。

QQuest・Android・iOS でも使える？

PC 版の VRChat 専用です。Quest・Android・iOS 向けのアバターには対応しておらず、それらで遊んでいる人からは正しく表示されません。

表示・見た目

Qキプフェルがピンク色になる／フェイスミラーに映る

Pet_gimmick フォルダを消して入れ直したときや、新しいバージョンを入れたときは、導入画面の 「更新する」 を押してください。フェイスミラー用のマテリアルなどが作り直されます。

Q衣装の一部やパーティクルが、フェイスミラーに映る

ステンシルに対応していないシェーダーの物は、フェイスミラーに映ることがあります（導入画面に表示されます）。lilToon などのシェーダーにすると隠せます。

Q表情がおかしい・表示されない

キプフェル・まめひなた本体のバージョンが古いと、表情が正しく出ないことがあります。最新版を入れ直してから、導入画面の 「更新する」 を押してください。

Qほかの人の画面で、位置がずれて見える

VRChat の同期のしくみ上、ほかの人の画面では少しずれて見えることがあります（完全には防げません）。止まってから数秒たつと、自分の画面と同じ位置に合わせ直します。

それでも直らないときは、Expression Menu の「表示」を一度オフにして、もう一度オンにしてください。位置などがリセットされて、自分のそばに出し直します。

Q壁や家具をすり抜ける

VRChat のアバターは、ワールドの壁や家具の当たり判定を使えません。そのため、物を通り抜けることがあります。

QUnity のシーンで、ついてくる方のキプフェルが見えない

シーンで 2 匹に見えないよう、実際についてくる方（「〇〇_Companion」）はふだん非表示にしています。VRChat では自動で表示されるので、そのままアップロードしてください。

着せ替え

Q着せ替えの方法は？

導入すると自分のアバターの中にできる「連れ歩きまめキプ（着せ替え用）」で着せ替えます。

導入画面の「デフォルト衣装」で元の服を 着る／脱ぐ を選び、「追加衣装」に着せたい衣装の Prefab をドラッグ＆ドロップします（Setup Outfit は不要です）。着せ替えたら 「更新する」 を押してください。

Q服が二重になる

元の服と重ならないよう、着替えるときは「デフォルト衣装」のチェックを外してください。

Q衣装がうまく着せられない

すべての衣装の着せ替えに対応しているわけではありません。キプフェル・まめひなたに対応していない衣装を、もちふぃった～ などのツールで合わせたものは、うまく着せられないことがあります（着せられるものもあります）。

うまくいかないときは、キプフェル・まめひなたに対応している衣装でお試しください。

Q着せ替えたキプフェルを、別のプロジェクトに移したい

導入画面の「着せ替え済みのキプフェルを書き出す…」で書き出し、移す先の「連れていく」の選択から「着せ替え済みのキプフェルを読み込む…」を選びます。

移す先にも、キプフェル・まめひなた本体、このギミック、衣装のシェーダー（lilToon など）、Modular Avatar を入れておいてください。衣装のデータには有料の物も含まれるので、人に配らないでください。

アップロード・設定

Qパラメータが多すぎてアップロードできない

このギミックは同期パラメータを約 66 bit 使います。アバター全体で 256 bit を超えるとアップロードできません。

顔文字・うろうろをオフにすると、それぞれ 3 bit 減らせます（Tools›連れ歩きギミック›詳しい設定（上級者向け））。

Q動きや表情を差し替えたい・増やしたい

動き（1回だけ・ずっと・放置モーション）と表情は、最初から入っているものを使います。差し替え・追加はできません。

Q大きさを変えたい

Expression Menu の「大きさ」で変えられます。はじめの身長は Tools›連れ歩きギミック›詳しい設定（上級者向け） の「① 大きさ」で変えられます。

更新・外す

Q新しいバージョンに更新したい

BOOTH から新しいパッケージをダウンロードしてインポートしたら、必ず導入画面の 「更新する」 を押してください。

Qギミックを外したい

導入画面の 「初期化する」 を押してください。完全に消すときは、そのあと Assets/Pet_gimmick を削除します。

自由です（収益化しているものも含みます）。クレジットの表記は任意です。

プログラムの改変は自由です。ただし、改変したものも含めて配布はできません。改変したことによる不具合は、サポートの対象外です。

このギミック（パッケージ・中のファイル・導入して作られたファイル）の再配布・譲渡・転売・共有は禁止です。

デジタル商品のため、お客様のご都合による返品・返金はお受けできません。不具合はアップデートで対応します。
